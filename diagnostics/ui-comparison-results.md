## 实际视觉观察

- 首页：旧版未选分组时中央显示 Select a node group；新版增加分组数量、检测快照统计、快捷分组与操作入口，信息利用明显增加。
- 登录：旧版是居中的 subs-check 小卡片；新版使用 NodePlane 品牌、双栏介绍和登录表单，层级、留白及密码显示入口的变化更明显。
- 计划任务：新版增加概览卡片和搜索区，原有任务表格保留。
- 节点详情：节点数据、表格和筛选结构整体延续旧实现；主要变化是工作区框架、侧栏、按钮、徽标和间距，不应描述为整个业务表格完全重做。展开侧栏也会占用更多横向空间。
- 规则编辑器：列表、定义编辑和 API 参考的布局仍可看出原有结构；新版主要统一外围工作区和基础控件。
- 设置：导航、容器和表单控件更加统一；新版留白更大，首屏信息密度有所下降。
- 移动端：新版提供抽屉导航和更明确的品牌，但双层顶部占用了更多高度。390px 节点详情中的 Run Check 工具栏按钮在两版都有裁切，新版可见内容更少。问题被原样保留，没有通过裁剪、换视口或改 CSS 隐藏。

结论：此次接入的最大收益是工作区、品牌、默认首页和基础组件的一致性；复杂业务组件与移动端空间利用仍需继续优化。前后变化同时来自组件接入及应用布局重构，不能归因于仅替换组件库。
